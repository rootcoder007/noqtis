:::caution[Not yet audited]
noqtis has not had an external security audit. Read the
[security page](/noqtis/security/) before relying on it.
:::

```sh
noqtis keygen -a ML-DSA-65 -o me          # me (secret), me.pub (public)
noqtis seal -k me results/                # writes noqtis.json + noqtis.sig
noqtis check -p me.pub results/           # exit 0: every file is as sealed
echo oops >> results/report.txt
noqtis check -p me.pub results/           # exit 1: report.txt: size differs
```

<CardGrid>
  <Card title="Capsules" icon="document">
    A folder plus `noqtis.json` (every file's size, SHA-256 and SHA3-256, in
    canonical JSON) and `noqtis.sig` (a signature over those exact bytes).
    Checking finds any changed, missing or added file.
  </Card>
  <Card title="Post-quantum, standard" icon="approve-check">
    ML-DSA (FIPS 204), SLH-DSA (FIPS 205), ML-KEM (FIPS 203) and HQC,
    byte-identical to the NIST ACVP test vectors and Wycheproof.
  </Card>
  <Card title="Fail closed" icon="warning">
    Every parser rejects anything the format does not define; a check that
    cannot be made is a failed check, never a silent pass.
  </Card>
  <Card title="Constant time" icon="setting">
    No branch or memory index depends on a secret, checked with valgrind
    (ctgrind); ML-DSA signing and ML-KEM decapsulation are also masked.
  </Card>
</CardGrid>
