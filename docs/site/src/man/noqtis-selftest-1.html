NAME

noqtis-selftest — run the known-answer self-test of noqtis

SYNOPSIS

noqtis selftest

DESCRIPTION

noqtis selftest runs nqselftest(3): fixed inputs through every algorithm family (SHA-2, SHA-3 and SHAKE, HMAC, ML-KEM, ML-DSA, SLH-DSA key generation, HQC, Ed25519 and a hybrid), each family's outputs compared by their SHA-256 with the known answers built into the library. It prints

selftest: every known answer matches
or names the failure, and takes about a tenth of a second.

EXIT STATUS

0 when every known answer matches, 1 when one does not, 2 on a usage error.

SEE ALSO

noqtis(1), nqselftest(3)
