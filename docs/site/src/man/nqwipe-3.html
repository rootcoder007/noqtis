NAME

nqwipe — erase secret data from memory

LIBRARY

libnoqtis, -lnoqtis

SYNOPSIS

#include <noqtis.h>

void
nqwipe(void *p, size_t len);

DESCRIPTION

nqwipe() sets the len bytes at p to zero through a volatile pointer, so the compiler cannot remove the stores as dead, even just before the memory is freed or goes out of scope. p may be NULL, and then nothing happens.

The library wipes every secret it holds (keys, seeds, shared secrets, intermediate state, freed memory of the capsule layer) before it returns, on every path. Callers wipe their own copies: secret keys, seeds and shared secrets they no longer need.

RETURN VALUES

None.

EXAMPLES

static uint8_t sk[4032];
/* ... sign with sk ... */
nqwipe(sk, sizeof sk);

SEE ALSO

explicit_bzero(3), noqtis(3), nqcteq(3)

CAVEATS

nqwipe() cannot erase copies outside the buffer it is given: registers, swap, core dumps or copies the caller made.
