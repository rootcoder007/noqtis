NAME

nqdchk, nqdrepn, nqdrepi, nqdrepj, nqdrepfree — check a capsule's data record against its files

LIBRARY

libnqd, -lnqd -lnoqtis

SYNOPSIS

#include <nqd.h>

int
nqdchk(const char *dir, nqdrep **rep);

size_t
nqdrepn(const nqdrep *r);

int
nqdrepi(const nqdrep *r, size_t i, const char **check, int *ok, const char **detail);

const char *
nqdrepj(const nqdrep *r, size_t i);

void
nqdrepfree(nqdrep *r);

DESCRIPTION

nqdchk() reads noqtis.data.json in dir (noqtis-data(5)) and checks the folder against it, one report row per check:

‘record’
the record reads, is of the format and canonical (the detail says what is wrong when not)
‘source’
one per source: its file is there, with the recorded SHA-256 (compared in constant time) and size
‘schema, ‘rule’’
one per schema: its file matches the columns, types, missing-value codes, ranges and sets; one per rule
‘recorded’
one per recorded check: it fails when the check was recorded as ‘fail’

A row about a file marked synthetic says ‘[synthetic]’ after the path. It checks nothing of the seal: check the capsule with nqchk(3) too.

nqdrepn(), nqdrepi() and nqdrepfree() read and free the report as nqrep(3) does a capsule's. nqdrepj() returns the numbers of row i as canonical JSON, for rows that have them (those of nqddrift(3)), or NULL. The strings stay valid until the report is freed.

RETURN VALUES

nqdchk() returns NQOK when every row passed and NQEVRFY when one failed (no record, or one that does not read, is a failed ‘record’ row); in both cases *rep is set. NQEARG and NQEMEM return no report. nqdrepi() returns NQEARG for a row that is not there.
