NAME

noqtis-algs — list the algorithms noqtis provides and their sizes

SYNOPSIS

noqtis algs

DESCRIPTION

noqtis algs prints a table with one row per signature algorithm (type ‘sig’) and per key encapsulation mechanism (type ‘kem’): its name, the public key, secret key and signature or ciphertext sizes in bytes, and for a KEM the shared-secret size. The names are those noqtis-keygen(1) accepts and key files carry; the sizes are those of nqssize() and nqksize() (nqsign(3), nqenc(3)).

EXIT STATUS

0, or 2 on a usage error.

EXAMPLES

$ noqtis algs
algorithm              type      pk      sk  sig/ct   ss
ML-DSA-44              sig     1312    2560    2420    -
ML-DSA-65              sig     1952    4032    3309    -
ML-DSA-87              sig     2592    4896    4627    -
SLH-DSA-SHA2-128s      sig       32      64    7856    -
...
ML-KEM-768             kem     1184    2400    1088   32
...
HQC-256                kem     7237    7333   14421   32
