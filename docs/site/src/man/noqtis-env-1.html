NAME

noqtis-env — record the environment of a run in the data record

SYNOPSIS

noqtis env [--rng kind [--seed seed]] [--lock file ...] dir

DESCRIPTION

noqtis env sets the env member of the data record of dir (noqtis-data(5)): os and arch (those this tool was built for), noqtis (its version), locale (LC_ALL, else LANG) and tz (TZ), when set; rng from --rng and --seed; and locks: the SHA-256 of each lock file named with --lock (a path in dir, up to 32), or else of each of renv.lock, uv.lock, poetry.lock, Pipfile.lock, requirements.txt, Cargo.lock, go.sum, package-lock.json, pnpm-lock.yaml, yarn.lock, environment.yml and Manifest.toml found at the top of dir. It replaces the env there. The language runtime and its packages (runtime) are filled by a binding, which knows them, with noqtis data put.

EXIT STATUS

0 when the record is written, 2 on a usage or file error.

SEE ALSO

noqtis-data(1), noqtis-diff(1), noqtis-data(5)
