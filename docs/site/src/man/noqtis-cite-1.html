NAME

noqtis-cite — print how to cite the data of a capsule

SYNOPSIS

noqtis cite [--format cff | bibtex] dir

DESCRIPTION

Prints, from the cite member of the data record of dir (noqtis-data(5)), a CITATION.cff (version 1.2.0, type dataset; the default) or a BibTeX ‘@misc’ entry: title, authors, year, version, DOI, URL and licence. Add the member with noqtis data put dir cite file.

EXIT STATUS

0 when printed, 2 on a usage error or a record with no cite.
