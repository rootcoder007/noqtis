NAME

noqtis-version — print the version of noqtis

SYNOPSIS

noqtis version

noqtis -V | --version

DESCRIPTION

noqtis version prints

noqtis <major>.<minor>.<patch>
the version of the library the tool runs on, as nqver() returns it (nqerr(3)).

EXIT STATUS

0, or 2 on a usage error.

EXAMPLES

$ noqtis version | cut -d' ' -f1
noqtis

SEE ALSO

noqtis(1), nqerr(3)
