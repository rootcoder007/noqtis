NAME

nqdstats, nqddrift — summarise a CSV file, and compare a later one with the summary

LIBRARY

libnqd, -lnqd -lnoqtis

SYNOPSIS

#include <nqd.h>

typedef struct {
  double psiwarn; /* 0.1 */
  double psifail; /* 0.25 */
  double alpha;   /* 0.001 */
  double minn;    /* 1000 */
  int benford;    /* 0 */
} nqddopt;

int
nqdstats(const char *dir, const char *path, const nqdcsvopt *o, char *out, size_t cap, size_t *outlen, char *why, size_t wcap);

int
nqddrift(const char *stats, size_t n, const char *file, const nqdcsvopt *o, const nqddopt *d, nqdrep **rep);

DESCRIPTION

nqdstats() reads the CSV file path in dir and writes its summaries to out as a ‘stats’ element in canonical JSON, for nqdput(3); o is as for nqdinfer(3) (its ranges unused), and may be NULL.

nqddrift() compares the CSV file at file (any path) with the ‘stats’ element stats (n bytes): one ‘drift’ row for the row counts, and per column a ‘drift’ row (passed or failed) or a ‘drift.warn’ row (passed, with a warning). Each column's row carries its numbers as JSON, read with nqdrepj(3). d sets the levels (NULL: the defaults above). noqtis-drift(1) defines the summaries, the tests, the levels and the error of the sketch.

Both hold every number of a column in memory while reading the file, 8 bytes each.

RETURN VALUES

nqdstats() returns NQOK, NQEBUF with *outlen set when cap is too small, NQEDEC for a file that is not CSV or has rows of different lengths, NQEIO for a file that cannot be read, NQELIM over the reader's limits. nqddrift() returns NQOK when no row failed and NQEVRFY when one did (an element that is not ‘stats’, or a file that cannot be read, is a failed row), with *rep set.
