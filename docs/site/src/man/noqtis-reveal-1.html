NAME

noqtis-reveal — check a file against a commitment

SYNOPSIS

noqtis reveal dir file salt

DESCRIPTION

noqtis reveal computes the commitment of file under the salt in the file salt (noqtis-commit(1)) and compares it, in constant time, with every commitment in the data record of dir. Check the capsule first (noqtis-check(1)): the commitment counts only if the record is the one sealed.

EXIT STATUS

0
the file matches a commitment (its number is printed)
1
it matches none: the file or the salt is not the one committed to
2
a usage or file error

SEE ALSO

noqtis-commit(1), nqdcommit(3)
