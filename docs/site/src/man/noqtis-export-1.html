NAME

noqtis-export — a capsule as in-toto, DSSE, RO-Crate or BagIt

SYNOPSIS

noqtis export --as intoto | dsse | rocrate | bagit [-k key] [-p key.pub] [-o file | dir] [-f] dir

DESCRIPTION

noqtis export describes the capsule dir (noqtis-capsule(5)) in a format other tools read. The capsule must check first, with the key in its seal (noqtis-check(1)); pin the key there with -p before exporting.

intoto
An in-toto Statement v1 (JSON): one subject per file, with its path and SHA-256, and a predicate of type https://rootcoder007.github.io/noqtis/spec/capsule/ holding the capsule's id, format, algorithm, key fingerprint, created time and meta.
dsse
That statement in a DSSE envelope (‘application/vnd.in-toto+json’), signed with -k over the envelope's PAE. Most DSSE tools do not verify post-quantum signatures; noqtis-verify(1) --dsse does.
rocrate
RO-Crate 1.1 metadata (ro-crate-metadata.json): the folder as a Dataset whose identifier is the capsule's id, each file with its size and SHA-256, the seal and the manifest as files. Put it beside the capsule's files to make the folder a crate; it is not listed in the manifest, so ‘noqtis check’ then reports it as an ‘extra’ file unless the folder is sealed again.
bagit
A BagIt 1.0 bag (RFC 8493) in the new folder -o: a copy of every file under data/, each checked against the manifest's SHA-256 as it is copied, its manifest-sha256.txt, bag-info.txt (the capsule's id as External-Identifier, Payload-Oxum), bagit.txt, and the seal and the manifest as tag files listed in tagmanifest-sha256.txt.
--as format
The format, as above.
-k key, --key=key
For dsse: the secret signature key.
-p key.pub, --pub=key.pub
Its public key. Default: key.pub.
-o file, --out=file
Write to file instead of standard output; for bagit, the bag's folder, which must not exist.
-f, --force
Replace file if it exists.

EXIT STATUS

0
Exported.
1
The capsule does not check.
2
A usage error, a key that cannot be read, a file that changed while it was copied, or a file or folder that cannot be written.

EXAMPLES

$ noqtis export --as dsse -k me -o results.intoto.json results
$ noqtis verify -p me.pub --dsse results.intoto.json
$ noqtis export --as bagit -o results-bag results
