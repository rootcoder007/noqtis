NAME

nqddiff — what changed between two capsules

LIBRARY

libnqd, -lnqd -lnoqtis

SYNOPSIS

#include <nqd.h>

int
nqddiff(const char *a, const char *b, nqdrep **rep);

DESCRIPTION

nqddiff() compares the capsule in folder a with the one in b and reports, as nqdchk(3) does, one failed row per difference: a ‘manifest’ row (passed) with the file counts, or saying a folder is not sealed; ‘file’ rows for files added, removed or changed between the manifests (read with nqfiles(3)); and rows named ‘source’, ‘schema’, ‘stats’, ‘check’, ‘env’, ‘cite’, ‘steps’ and ‘commits’ for the differences of the data records, as noqtis-diff(1) describes. Nothing is checked.

RETURN VALUES

NQOK when nothing differs, NQEVRFY when something does, with *rep set in both cases; NQEARG or NQEMEM without a report.

SEE ALSO

noqtis-diff(1), nqdchk(3), nqfiles(3), noqtis-data(5)
