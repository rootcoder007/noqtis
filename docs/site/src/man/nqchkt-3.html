NAME

nqchkt — check a capsule and its RFC 3161 timestamp

LIBRARY

libnoqtis, -lnoqtis

SYNOPSIS

#include <noqtis.h>

int
nqchkt(const char *dir, const uint8_t *trust, size_t trustlen, const uint8_t *const *anc, const size_t *anclen, size_t nanc, nqrep **rep);

DESCRIPTION

nqchkt() is nqchk(3) with nanc trust anchors for time-stamping authorities (TSAs): anc[i] is a DER X.509 certificate of anclen[i] bytes, for i below nanc, at most 32.

With anchors, the seal must carry a ‘timestamp’: the base64 of an RFC 3161 time-stamp token. The ‘timestamp’ row passes only when

  • the token parses as a strict DER RFC 3161 token;
  • its message imprint is its own hash (SHA-256, SHA-384 or SHA-512) of the decoded ‘signature’ bytes of the seal;
  • its signature verifies under the TSA's certificate, whose path leads to one of the anchors and is valid at the token's genTime;
and the row's detail then gives the genTime. A seal without a timestamp fails the row.

With nanc 0, nqchkt() is exactly nqchk(): a timestamp present fails its row (“not checked: no TSA trust anchors given”), and no timestamp gives no row.

The timestamp proves that the signature existed at genTime, according to the TSA. It does not make an untrusted seal key trusted; pin the key with trust.

RETURN VALUES

As for nqchk(3), and also:

[NQELIM]
nanc is over 32. No report.
[NQEARG]
nanc is nonzero and anc or anclen is NULL, or an anchor is NULL or empty. No report. An anchor that is not a certificate fails the ‘timestamp’ row instead.

EXAMPLES

const uint8_t *anc[1] = {tsa_der};
size_t anclen[1] = {tsa_der_len};
nqrep *rep = NULL;
int rc = nqchkt("results", pk, sizeof pk, anc, anclen, 1, &rep);

SEE ALSO

nqchk(3), nqrep(3), noqtis-capsule(5)

STANDARDS

Internet X.509 Public Key Infrastructure Time-Stamp Protocol (TSP), RFC 3161, August 2001. Internet X.509 Public Key Infrastructure Certificate and CRL Profile, RFC 5280, May 2008.

CAVEATS

Neither the library nor noqtis-seal(1) can yet obtain a timestamp, and noqtis-check(1) takes no anchors; timestamps are checked only through this function.
