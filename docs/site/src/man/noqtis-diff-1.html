NAME

noqtis-diff — what changed between two capsules

SYNOPSIS

noqtis diff [-j | --json] dir dir

DESCRIPTION

noqtis diff compares two capsule folders, the first as before and the second as after, and prints one row per difference:

file
a file added, removed or changed (size and SHA-256) between the two manifests, when both folders are sealed
source
a source added or removed in the data records (noqtis-data(5)), or the fields that changed, old and new
schema
a column added, removed or changed (its type, missing values, range), or another field of a schema (rows, delimiter, rules)
stats
a summary's row count, or a column's count, median and the population stability index between the two summaries (over the same bins, or over the categories of either)
env, cite
fields that changed, or the member added or removed
steps, commits
how many there are, and the first that differs
check
a recorded check added, removed or changed

Nothing is checked: a seal or record that does not verify is compared as it reads. Run noqtis-check(1) and noqtis data check on each first.

-j, --json
Print one line of JSON: 
{"from":"<dir>","to":"<dir>","same":<bool>,
 "rows":[{"what":"<kind>","differs":<bool>,"detail":"<text>"},...]}

EXIT STATUS

0
nothing differs
1
something does
2
a usage error, or a path that is not a folder

EXAMPLES

$ noqtis diff results-2025 results-2026
      manifest  3 files, then 3
diff  file      data/a.csv changed: 89 -> 111 bytes, SHA-256 7a16...
diff  schema    data/a.csv: rows {"max":3,"min":3} -> {"max":4,"min":4}
results-2025 and results-2026: 2 differences
