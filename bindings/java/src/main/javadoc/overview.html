NOQTIS seals the exact files behind a result with a post-quantum signature, so anyone can check later, offline, that nothing changed. This package binds the NOQTIS C11 library through the Foreign Function and Memory API (JDK 22 or later): ML-DSA and SLH-DSA signatures, hybrids with Ed25519, ML-KEM and HQC, SHA-2 and SHA-3, and sealed folders (capsules). The jar carries the library for Linux, macOS and Windows on x86-64 and arm64.

Status: unaudited. The code has not had an external security audit; do not rely on it for anything that matters yet.
